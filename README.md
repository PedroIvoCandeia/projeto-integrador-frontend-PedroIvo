# projeto-integrador-frontend-PedroIvo

## Sobre o projeto

O Sabor & Arte é um projeto de desenvolvimento front-end que apresenta o cardápio de um restaurante fictício.

O site permite visualizar pratos principais, bebidas e sobremesas, consultar preços, pesquisar produtos e filtrar os itens por categoria.

Também possui um carrinho de compras interativo, no qual o usuário pode adicionar produtos, alterar quantidades e visualizar o valor total do pedido.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- LocalStorage

## Funcionalidades

- Apresentação do restaurante.
- Exibição dos produtos do cardápio.
- Pesquisa de produtos pelo nome ou descrição.
- Filtro por categoria.
- Adição de produtos ao carrinho.
- Aumento e diminuição da quantidade de produtos.
- Cálculo automático do valor total.
- Armazenamento do carrinho no navegador.
- Layout adaptável para computadores, tablets e celulares.

## Como executar o projeto

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Entre na pasta `Sabor_e_arte`.
4. Abra o arquivo `pedro.html`.
5. Execute utilizando a extensão Live Server.
